type: Added
title: The library — a bestiary of every monster
---

A reference site now ships alongside the game at `/library/`: a page for each of the 104 monsters with what it fields on every difficulty, where it spawns, what it drops and its mechanics, plus its dialogue and last words behind a spoiler cover you have to click. Every page is generated from the same content the game itself is built from — and its derived numbers come from calling the game's own code — so it is rebuilt with each release and cannot fall out of step. The pages carry no JavaScript and never load the game, so they open instantly.
