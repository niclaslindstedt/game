type: Added
title: The Mod SDK has its own licence
---

`mod/` is now licensed separately from the rest of the repository
(`mod/LICENSE.md`): the samples a modder copies — `mod/examples/` and the
format docs — are public domain (CC0), your mod is yours, and the toolchain in
`mod/tools/` is licensed for authoring content for this game rather than for
reuse in another one.
