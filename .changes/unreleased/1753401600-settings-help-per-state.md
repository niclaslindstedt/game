---
type: Changed
title: Settings help describes the current setting
---

Every help line in the settings now describes only the state the setting is actually in, instead of packing both into one wrapping line — AUTO-EQUIP reads "STRONGER FINDS GO ON THE MOMENT YOU GRAB THEM" when it's on and "STRONGER FINDS WAIT IN THE BAG UNTIL YOU WEAR THEM" when it's off, and the same goes for every other switch and cycled value.
