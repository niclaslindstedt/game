title: LOAD GAME is absent on a first launch, not greyed out
---

The title menu's LOAD GAME row no longer sits greyed out with a line explaining
why on a fresh install — it simply isn't there until there is a hero to load.
A dead row owes the player an explanation, and that explanation was a second row
of text hanging off the centred front door; NEW GAME above it already says what
to do first.
