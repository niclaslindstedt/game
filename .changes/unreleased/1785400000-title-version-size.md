type: Changed
title: The build's version reads at a glance from the title screen
---

The version (and, in the developer builds, the commit beside it) in the title
screen's footer now draws at twice the size. It was set at the pixel font's 1×
scale — legible on a desktop, a smear on the phone the game is designed
around, which is exactly where someone reporting a bug is asked to read it.
