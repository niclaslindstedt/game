type: Added
title: The library now carries the achievements
---

The reference site at `/library/` grew an eighth section: every badge the game
can award, filed the way the shelf files them. Each category page lists what its
badges ask for and what they pay, the relic wall and the companion roster are
drawn as racks that link straight to the relic or the ally, and the index carries
the half the game never shows you — what each effort tier is worth, and which
badges reach a Game Center or Steam profile.
