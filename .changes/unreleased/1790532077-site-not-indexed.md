type: Changed
title: The website asks search engines not to index it
---

Every page of the website — the game, the library, the privacy and contact pages — now tells search engines not to list it, and the site no longer publishes a sitemap, an `llms.txt` or machine-readable descriptions of the game and its pages. A shared link still shows the game's name, description and picture. Playing, installing and running offline are unchanged.
