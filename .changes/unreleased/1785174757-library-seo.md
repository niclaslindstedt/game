title: Library search results and internal links
---

The library's meta descriptions now read grammatically ("is an artifact", "is a
charm", "is footwear" rather than "a artifact", "a a charm", "a footwear"), every
page carries a unique title and description, a named relic's BUILT ON link
reaches the page its base is written up on instead of a 404, and each base page
lists the relics built on its whole grade ladder. The header nav no longer
scrolls a library page sideways on a phone.
