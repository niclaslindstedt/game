---
type: Changed
title: Running no longer empties the sprint pool
---

Stamina drains a fifth as fast, so ordinary running stops bottoming the pool
out: a fresh hero used to be able to sustain only a 45–55% run duty cycle
against a map that demands more like 80%, which left him at ZERO stamina for
41% of the opening level with regen locked out for 72% of it, drinking a
stamina potion every thirty seconds just to keep moving. The pool now survives
a normal fight, so what it funds is a BURST — jumps, and a drink saved for a
sprint you choose to spend rather than one the map extracts.
